# Zephyrus

Zephyrus — настольный медиа-загрузчик для Windows с аккуратным интерфейсом. Он работает на базе **yt-dlp** и **FFmpeg**: вставляете ссылку, выбираете формат и качество, получаете готовый файл.

Автор: **RonovaDev**
Лицензия: **GPL-3.0**

---

## Возможности

- Скачивание видео и аудио с сотен сайтов, которые поддерживает yt-dlp.
- Форматы видео: MP4, MKV, WEBM. Форматы аудио: MP3, M4A, OPUS, FLAC, WAV.
- Выбор качества: лучшее доступное либо ручной выбор. В ручном режиме качество видео и качество звука выбираются отдельно, а FFmpeg склеивает их в один файл.
- Предпросмотр ссылки: обложка, название, автор и длительность до начала загрузки.
- Плейлисты целиком, очередь загрузок, отмена текущей загрузки.
- Прогресс в реальном времени: процент, скорость, оставшееся время, размер.
- Сессии: вход в аккаунт сайта во встроенном браузере для закрытых, возрастных и платных видео. Поддерживается несколько профилей на сайт и переключение между ними.
- История загрузок с поиском. Если файл удалён с диска, запись бледнеет и становится доступна кнопка «Скачать повторно».
- Встраивание обложки, метаданных и субтитров, SponsorBlock, ограничение скорости, прокси.
- Светлая, тёмная и системная темы, несколько акцентных оттенков и собственный цвет.
- Обновление движка одной кнопкой, без переустановки программы.

## Установка

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте файл `Zephyrus_Setup_<версия>.exe`.
3. Запустите установщик, выберите диск и папку, при желании отметьте ярлыки.

Требования: Windows 10 или Windows 11, 64-разрядная версия. Дополнительно ничего ставить не нужно: yt-dlp и FFmpeg уже входят в установщик.

Windows SmartScreen может показать предупреждение «Неизвестный издатель», потому что установщик пока не подписан цифровой подписью. Для продолжения нажмите «Подробнее», затем «Выполнить в любом случае». Контрольные суммы лежат рядом с релизом в файле `SHA256SUMS.txt`.

## Как пользоваться

### Загрузка

1. Вставьте ссылку в поле или нажмите «Вставить».
2. Выберите тип: видео или аудио.
3. Выберите режим качества:
   - **Лучшее доступное** — программа сама выберет максимум. Можно ограничить качество, например до 1080p.
   - **Выбрать вручную** — откроются списки реальных форматов. Видео и звук выбираются отдельно, затем склеиваются.
4. Нажмите «Скачать».

Если ссылку нужно добавить, пока идёт другая загрузка, она встанет в очередь.

### Сессии

Вкладка нужна для контента, который доступен только после входа.

1. Нажмите на плитку сайта и войдите в аккаунт в открывшемся окне.
2. Нажмите «Сохранить сессию» и дайте профилю имя.
3. Дальше cookies подставляются автоматически, когда вы скачиваете ссылку этого сайта.

Профили хранятся в зашифрованном виде и привязаны к вашей учётной записи Windows. Их можно переименовать, сделать активными или удалить полностью.

Некоторые сайты, в частности Google и YouTube, могут не пускать во встроенный браузер. В этом случае экспортируйте `cookies.txt` расширением для браузера и используйте кнопку «Импорт cookies.txt».

### История

Все загрузки сохраняются в таблицу. Двойной клик по строке показывает файл в проводнике. Кнопка «Очистить историю» удаляет только записи, сами файлы остаются.

### Настройки

Папка загрузок, тема и акцентный цвет, форматы по умолчанию, шаблон имени файла, сеть и обновление движка.

## Обновление движка

Сайты часто меняются, и yt-dlp обновляется чаще самой программы. Если загрузка перестала работать, откройте **Настройки**, затем **Обновить движок**. Программа скачает свежий yt-dlp с GitHub, проверит контрольную сумму и заменит файл. Права администратора не нужны.

## Где хранятся данные

Всё, что программа создаёт во время работы, лежит в `%LOCALAPPDATA%\Zephyrus`:

| Папка | Содержимое |
|-------|------------|
| `bin` | рабочие копии yt-dlp и FFmpeg |
| `data` | база данных SQLite и ключ шифрования |
| `profiles` | зашифрованные профили cookies |
| `cache` | временные файлы и значки сайтов |
| `logs` | журнал работы |

Папка установки в `Program Files` остаётся неизменной. При удалении программы установщик спросит, нужно ли стереть и эти данные.

## Сборка из исходников

Нужны Python 3.12 и, для установщика, Inno Setup 6.3 или новее.

```bat
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python tools\fetch_binaries.py
python tools\make_icon.py
python main.py
```

Для полной сборки установщика запустите `build.bat`. Сборку на GitHub Actions запускает тег вида `v1.0.0` либо ручной запуск во вкладке Actions.
